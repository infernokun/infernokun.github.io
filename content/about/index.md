<div class="ik-cards">

  </div>
  <div class="ik-card">
    <h3>Game mods and modding tools</h3>

  </div>
  <div class="ik-card">
    <h3>Steam Deck and Linux bits</h3>
    <p>Small plugins that fix something that annoyed me.</p>
  </div>
  <div class="ik-card">
    <h3>Game dev experiments</h3>
    <p>Unreal and Unity projects I use to learn animation, cameras and gameplay systems.</p>
  </div>
</div>

My code is on [GitHub](https://github.com/infernokun).
