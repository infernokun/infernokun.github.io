I'm Javoris. Online I go by InfernoKun.

I build the tools I want to use and then keep going until they hold up. Most of what I make falls into a few buckets:

- **Self-hosted web apps.** Angular front ends, Spring Boot APIs, Python services for the heavy lifting, all in Docker and built by my own GitLab.
- **Game mods and modding tools.** Mostly Telltale's games, where I take apart archives and Lua bytecode to change how they behave.
- **Steam Deck and Linux bits.** Small plugins that fix something that annoyed me.
- **Game dev experiments.** Unreal and Unity projects I use to learn animation, cameras and gameplay systems.

This site is where I write those projects up: why I started them, how they work, and what broke along the way.

My code is on [GitHub](https://github.com/infernokun).
